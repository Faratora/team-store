# Team Store

Командный учебный проект — простой онлайн-магазин.

## О проекте

Приложение для демонстрации навыков командной разработки. Пользователь может
просмотреть каталог товаров, фильтровать и сортировать их, добавлять товары
в корзину и применять промокод для скидки.

## Функциональность

- Страница «О нас» с информацией о команде.
- Каталог товаров с карточками (название, категория, цена, изображение).
- Поиск по названию, фильтр по категории и диапазону цен, сортировка.
- Корзина: добавление, удаление, изменение количества, подсчёт суммы.
- Промокод `SALE10` — скидка 10% на общую стоимость.
- Сохранение корзины в `localStorage`.
